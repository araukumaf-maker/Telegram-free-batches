# PW Extractor Bot

Telegram bot for accessing authorized PW free batches.

## Features
- 🔐 OTP Login / 🔑 Manual Token
- 📚 My Batches
- 📝 Notes / DPPs download
- 💝 Donate with auto-verify

## Setup
1. `pkg install python python-pip termux-api -y`
2. `pip install python-telegram-bot requests`
3. `.env` file banao `.env.example` se
4. `python pw_bot.py`
